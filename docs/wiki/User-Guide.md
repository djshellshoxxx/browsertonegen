# User Guide (summary)

The full guide is `docs/USER_GUIDE.md`; recipes are in `docs/AUTOMATION_RECIPES.md`.

- Open the live app, pick a reference preset or enable and edit a tone, then press **Start**. The default bank has eight slots; up to 32 voices can run at once.
- **Advanced** enables phase, routing, timing, harmonics, modulation, sequences and stereo tools.
- Automation, MIDI and audio saving are available in simple mode.
- **Stop** fades the output. **Escape / Panic** silences it at once. **Space** controls the transport outside focused controls.
- 0.2 adds phase inheritance for live-added matching tones, per-tone automation lanes, channel-specific MIDI CC mappings with MIDI Learn, and offline WAV rendering or live recording.
