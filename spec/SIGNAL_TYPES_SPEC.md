# Signal Types Spec

Version: 0.1.0-beta.1

Each voice includes enabled, muted, solo, frequency, waveform, amplitude 0..1 linked to -80..0 dB (0 amplitude displays -80), phase -360..360 degrees, pan -1..1, routing both/left/right, inversion, delay 0..3600 s, duration 0=continuous or 0.001..3600 s, fades 0..30 s (overlap multiplies envelopes), pulse width .01...99. Sine exact sampled sinusoid; saw/reverse saw and pulse/square use PolyBLEP anti-alias approximation; triangle uses first 16 odd harmonic slots below Nyquist. Additive uses signed coefficients for 1..32 harmonics, automatically omits above-Nyquist harmonics and normalizes by sum of absolute coefficients. Pattern all/odd/even/square/triangle and rolloff h^-r with r 0..4. White uniform seeded noise; pink octave sample-and-hold sum, brown leaky integrator, blue first difference of approximate pink, violet first difference of white. Noise colors approximate, no grey-noise compliance claim. Channel both uses equal-power pan (center -3.01 dB per channel); left/right route full voice amplitude. Stereo polarity preset uses equal signals opposing polarity. Alternation/pan sweep modulate routing on sample clock. AM/tremolo=(1+d*sin)/[1+d]; ring multiplies carrier by LFO; FM depth in Hz; vibrato depth in cents. Source sine LFO. All modulations share sample-clock time.
Sweeps per voice use start=endpoints, duration .01..3600, linear or log (exponential frequency trajectory means log spacing), forward/reverse/pingpong, loop, repeats 1..100, fade settings. Pingpong repetition is one round-trip. Steps have 2..128 frequencies inclusive endpoints, linear/log spacing, dwell .001..60, transition 0..1 of dwell, forward/reverse/pingpong, repetitions/loop. Pingpong visits endpoints once: 0,1,...N-1,N-2,...1. Sequence replaces only that voice waveform/frequency by stage; stages tone/silence/sweep/white/pink/brown, duration .001..3600, repeat 1..100; global stage list has at most 64 stages. Phase continuous across stages; fades can be applied via voice envelope. Sequence end silences voice unless looping.

Requirements: ENG-TONE-001, ENG-TONE-002, ENG-TONE-003, ENG-WAVE-001, ENG-NOISE-001, ENG-ADD-001, ENG-GROUP-001, ENG-SWEEP-001, ENG-STEP-001, ENG-STEREO-001, ENG-SEQ-001, ENG-MOD-001. See REQUIREMENTS_MATRIX.md for verification.
