# Accessibility Spec

Version: 0.1.0-beta.1

Semantic landmarks, skip link, labeled number/select/range controls and groups, details/summary, visible teal focus, descriptive voice action names, native keyboard numeric/range behavior, logical document order. Space transport only when not in input/textarea/select/button/link or contenteditable. Escape Panic anywhere. Pressed-state mute/pause/solo communicated using native checkbox or aria-pressed. Status role=status, errors role=alert. Canvas labeled with supplementary textual peak/RMS/active frequency data. No dependence on color. Touch targets min 40 px. Reduced motion disables animation. Mobile 390 px and text zoom 200% must not cause body overflow. No claim of certified accessibility without an external audit.

Requirements: A11Y-001. See REQUIREMENTS_MATRIX.md for verification.
