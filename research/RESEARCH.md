# Research and architecture decisions

Research date: 2026-10-03. Consulted primary platform docs and official product manuals. No third-party source code copied.

* [Web Audio specification](https://www.w3.org/TR/webaudio/) describes AudioContext, OscillatorNode, GainNode, StereoPannerNode, ChannelMergerNode, BiquadFilterNode, WaveShaperNode, PeriodicWave and AudioWorklet. Native oscillators handle built-in waveforms well; a custom sample-clock worklet gives explicit phase, pulse width and identical export math. Nyquist limits must be based on actual context sample rate. Custom discontinuous signals need anti-alias treatment. PolyBLEP is an approximation; no precision calibration claim.
* [MDN AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet): secure context, separate audio thread. Worklet module fetch uses relative URL. No main-thread scheduling for timing. Maintain one context and disconnect retired nodes. A dedicated worker renders the same DSP for export without blocking interface. An OfflineAudioContext was considered; worker avoids offline/live algorithm divergence.
* [MDN autoplay](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay): resume/create context only after gesture. URL restoration and preset import stay silent.
* [REW signal generator](https://www.roomeqwizard.com/help/help_en-GB/html/siggen.html): studied groups tones/multitone/noise/sweeps, variable duty, stereo output, polarity, headroom display and WAV rates/depths. This tool provides digital generator output; unlike REW it does not capture microphones, measure room response or report calibrated SPL/volts. External hardware and analysis required for frequency-response tests. Browser and soundcard filtering prevent guaranteed acoustic ultrasonic/infrasonic output.
* [Audacity Tone](https://manual.audacityteam.org/man/tone.html), [Chirp](https://manual.audacityteam.org/man/chirp.html), [Noise](https://manual.audacityteam.org/man/noise.html): reference constant/swept signals and color conventions. Logarithmic sweep is exponential change of Hz versus time. Pink/brown are useful but browser noise here is approximate.
* [noise.js](https://github.com/zacharydenton/noise.js) MIT project reviewed at overview level for colored-noise separation. No code copied; original seeded octave-noise implementation. This avoids depending on deprecated ScriptProcessor examples. No copied license obligations introduced.
* Circuit Drift Labs BRAND.md/index.html/styles.css plus TrackStats/LoudnessBatch/MIDItest index.html examined via repository API. Family navigation points to owner.github.io/circuitdriftlabs. Charcoal panels, teal/orange accents, geometric frame and system fonts carried over.

## Node decisions
GainNode handles transport fades and immediate emergency mute. StereoPannerNode/ChannelMergerNode are alternatives to explicit DSP route math; routing is calculated in shared DSP to ensure export parity. BiquadFilterNode could color noise but would require export parity and careful filter state; octave noise/leaky integration used instead. WaveShaperNode distortion was unnecessary; bounded output clamp is explicit and metered. PeriodicWave enables native additive spectra but phase-offset and same export requirements favor direct additive synthesis.

## Limits and verification
Timers are sample-clock accurate within a running context, but output hardware latency and clock accuracy are outside browser control. AudioContext sample rate may differ from requested device setting. Pause suspends the clock. Desktop/mobile performance must be measured; 32-voice support is a software cap, not a universal real-time performance guarantee. Export memory budget capped to 120 seconds. No scientific claims about binaural beat effects. Beta excludes grey noise, speech channel announcements and PWA caching; stereo channel labels/test patterns remain usable without them.
